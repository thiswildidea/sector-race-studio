# 行业板块竞速动画工作室

把 A 股行业与主题板块的表现做成抖音竖屏的「条形竞速」动画：十几条横向条形
互相超车，名次一路变到最后一帧，在浏览器里直接导出 MP4。
不装 Python 库、不装 ffmpeg、不装任何第三方软件。

这是同系列的第三个工具，前两个分别画全市场成交额和个股量价。它们共用同一套
基建（单文件 HTML + 系统自带 csc 编译 exe + `--app` 模式启动 + MediaRecorder 录制），
区别只在核心画面。

---

## 为什么是竞速

前两个工具本质都是「一条时间序列长出来」，观众看完前几秒就知道结局。
竞速是多条序列互相超车，悬念挂到最后一帧——这是数据类短视频最吃香的形态，
而它需要的数据腾讯接口全都给得到。

## 功能清单

### 板块清单

三选一，面板上直接切：

| 清单 | 内容 | 适合讲 |
|---|---|---|
| 中证一级行业 | 能源、材料、工业、可选消费、主要消费、医药卫生、金融、信息技术、通信、公用事业 | 全市场板块轮动（互斥且穷尽，10 条竖屏宽度刚好） |
| 热门主题 | 白酒、证券、银行、医疗、军工、传媒、新能源、新能源车、环保、红利、煤炭、有色金属、基建、农业、智能家居 | 具体赛道的强弱对比（辨识度高） |
| 自定义 | 在上面两套的并集里自己勾，3–16 个 | 只比自己关心的那几个 |

所有指数代码都经过实测：快照与日线都能取到数据。

### 竞速指标

- **累计涨幅 %**：区间起点全部归零，长度就是这段时间涨了多少。有正有负，
  零轴居中，正红负绿。叙事是「这三个月谁涨最多」。
- **累计成交额 亿**：区间内成交额逐日累加，单调增长。叙事是「钱在往哪个板块跑」。

切换指标不用重新取数，动画即时重建。

### 其余参数

数据区间（近 1/3/6/12 月或自定义）、视频时长 10–180 秒、分辨率 720p/1080p/1440p、
帧率 30/60、清晰度三档、抖音安全区参考线、标题文字、图表左右下边距——
这几项与同系列另外两个工具完全一致。

标题留空会按「清单名 + 指标」自动生成，例如「热门主题板块涨幅竞速」。

## 竞速动画是怎么做平滑的

朴素做法是每跨一个交易日就把条形挪到新名次，结果是整排条形一格一格地跳。
这里的处理是**让名次本身参与插值**：

1. 预先算出每个交易日每个板块的名次 `rank[k][i]`。
2. 播放时间映射成一个带小数的「日索引」`pos`，取相邻两日 `i0`/`i1`。
3. 纵向位置 = 两日名次按 `smoothstep` 插值，横向长度 = 两日数值线性插值。

于是两条互换名次时是平滑地交叉而过，而不是瞬间对调。整个过程无状态——
任意时间点 `t` 都能独立算出画面，所以拖动参数后重画、导出时逐帧录制都不会错位。

坐标轴范围同样逐日计算并插值，否则每跨一天整排条形会一起突然伸缩。轴的两端
各留出一截空白（负侧 22%、正侧 16%），因为数值标签画在条形末端的外侧，
不留的话最长的那根会把标签顶进左边的板块名里。

## 数据与口径

数据来自腾讯财经日线接口 `proxy.finance.qq.com/.../newfqkline/get`，每个板块指数
单独拉一次，串行请求，十几个几秒就完。两条清洗规则与同系列工具一致：

- **剔除未收盘的当日**：收盘前的当日 K 线只有集合竞价量，留着会让最后一天的
  成交额塌一个量级。
- **只保留所有板块都有数据的交易日**：某个板块缺一天就会让那一帧的名次凭空跳动。

成交额字段接口给的是万元，程序里换算成亿元。

## 文件说明

| 文件 | 作用 |
|---|---|
| `sector_race_studio.html` | 应用本体，单文件，含界面、抓数、渲染、导出全部逻辑 |
| `SectorRaceStudio.cs` | exe 启动器源码，内嵌上面的 HTML 并以 `--app` 模式拉起浏览器 |
| `build_exe.ps1` | 用系统自带 csc.exe 编译 exe，并打包出 `dist/` 与分发 zip |
| `启动-行业板块竞速动画.cmd` | 免 exe 的降级启动方案，效果完全一致 |
| `app.manifest` | exe 的清单，声明 DPI 感知与兼容性 |
| `gen_icon.py` | 纯 `zlib` + `struct` 手写 PNG 再套 ICO 头，生成 `app.ico`，不依赖 Pillow |

`app.ico`、`dist/`、`*.exe`、`*.zip` 都是生成物，已在 `.gitignore` 中排除。

注意 `build_exe.ps1` 含中文，必须存成 **UTF-8 with BOM**——PowerShell 5.1 会把
无 BOM 的脚本按 ANSI 读，中文全变乱码，解析直接失败。

## 使用方式

直接用：浏览器打开 `sector_race_studio.html`，按 ①②③ 走。

重新打包 exe：改完 HTML 后跑一次

```powershell
.\build_exe.ps1
```

## 已知限制

- **一次最多 16 个板块**，再多竖屏就挤成条形码了；少于 3 个没有竞速可言。
- **单次最多约 640 个自然日**，腾讯接口一次请求的 K 线条数上限。
- **导出耗时等于视频时长**，MediaRecorder 按墙钟给帧打时间戳。
- **产出是分片 MP4**，投稿平台没问题，拖进剪映做二次剪辑偶有时间轴识别异常。
- **需要 Edge 或 Chrome**，H.264 编码能力由浏览器内核提供。
- **exe 未做代码签名**，部分企业级安全软件会直接误删，此时改用 cmd 启动器。
